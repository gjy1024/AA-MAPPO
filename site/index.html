ATTENTION, MADE VISIBLE

“关注谁”，
可以怎样理解？

拖动三个实体与查询的匹配分数，观察 Softmax 如何形成归一化权重。数值仅用于解释机制，不是训练网络的实测注意力。

数学教学示例
αj = exp(zj) / Σ exp(zk)
实际分数 z 来自 QKᵀ / √dk。不同头可学习不同表示，具体语义需通过实验检验。
—
—
—
权重非负且和为 1；高权重表示当前聚合中的相对关注，不自动构成因果解释。
PPO clipping

裁剪代理目标的部分更新激励，不保证实际概率比始终在裁剪区间内，也不保证真实性能严格单调提高。

复合奖励

引导通信、感知代理、碰撞和速度代价之间的折中。较高奖励不自动证明 Pareto 最优或绝对安全。

实现与论文

本页解释算法结构。具体版本是否完成实体分组、掩码和双侧注意力，须结合代码与实验记录核查。

公开、具体、可核查

02

让数据成为可维护的接口

回放文件采用开放 JSON 格式。导入在浏览器本地进行，不会上传文件。

评估数据结构（字段示意）
{
  "schema_version": "1.0",
  "kind": "evaluation",
  "provenance": {
    "status": "illustrative",
    "policy": "rule_controller",
    "seed": 0,
    "checkpoint": null
  },
  "config": { "map_size": 100, "dt": 0.1 },
  "users": [[37, 65], [73, 38]],
  "trajectory": [
    { "step": 0, "time": 0,
      "positions": [[10, 20], [13, 80], [86, 80]],
      "metrics": {} }
  ]
}

来源信息与数值同样重要。

policy 记录实际控制策略；checkpoint 记录模型来源；seed 标识运行随机种子；notes 说明简化与限制。

完整格式与评估命令以仓库文档为准。导入成功仅表示文件结构有效，不构成科学结果认证。
