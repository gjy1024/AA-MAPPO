# 实验协议

本文件规定维护版的验证方式。四组历史日志已经恢复，维护版已有512步短训练闭环；以下完整多种子矩阵仍是后续计划，不提供虚构的提升比例、碰撞率或置信区间。已执行检查的范围见根目录[验证记录](../VALIDATION.md)。

## 1. 已恢复的历史记录

本地材料中存在四类算法的核心代码快照、`run1`训练日志、模型权重及截图：`6G_ISAC_Attention`、`Standard_MAPPO`、`No_Clip_MAPPO`、`Naive_Reward_MAPPO`。这些是真实历史材料，可以标明legacy后展示；它们不等于维护版的新结果。

现有日志可用于重新绘制其实际记录的reward、value loss、ratio、entropy等曲线。独立分项指标、完整随机种子信息、检查点与代码快照的精确对应关系，仍需核对。不能仅凭文件夹名或`run1`断言有多少个独立训练种子。

Naive Reward的训练目标与复合奖励不同，其总奖励不可不加说明直接横向比较。No_Clip的原论文设置是ε=5.0，属于大幅放宽裁剪；它不等于公式上完全移除裁剪。

## 2. 先确认实现，再比较性能

只有在 [实现审计](IMPLEMENTATION_AUDIT.md) 中的结构、动作、环境和入口问题完成验收后，才开展主要对比。修改实体 token、奖励定义、运动积分或动作边界后，应重新训练对应模型。旧权重和旧曲线不能自动归属于新实现。

每个实验要写出待检验的问题，例如：“在相同输入和训练预算下，实体注意力是否改善独立测试场景中的任务指标？”避免把“注意力一定过滤噪声”预设为结论。

## 3. 最小核心实验矩阵

已随仓库提供的维护版运行是`attention_mode=both`、训练seed7、512个环境步。其3个评估场景种子为1001、1002、1003，仅用于验证训练—保存—重新加载—评估流程，不填入下面的完整性能对比表。

| 变体 | Actor注意力 | Critic注意力 | 目的 |
| --- | --- | --- | --- |
| MLP-MAPPO | 否 | 否 | 基础参照 |
| Actor-Attention | 是 | 否 | 检查执行侧表征的作用 |
| Critic-Attention | 否 | 是 | 检查价值评估侧表征的作用 |
| AA-MAPPO | 是 | 是 | 检查完整组合及交互作用 |

建议每组先做 5 个独立训练种子，共 20 次训练；预算不足可以先做 3 个，但需说明不确定性。5 不是统计充分性的保证。四组使用同一奖励、环境步预算、观测信息、评估场景和模型选择规则。MLP-MAPPO 与 AA-MAPPO 两组可以复用于主性能比较，不需要重复训练。

注意力增加参数时，增加一个参数量接近的 MLP 对照，避免把模型容量变化全部归因于注意力。各算法应有相近的调参预算，并公开搜索范围与选择依据。

## 4. 统一评估指标

| 指标 | 定义或建议口径 | 单位与注意事项 |
| --- | --- | --- |
| 累积奖励 | 一个评估回合内奖励之和 | 只比较相同奖励定义下的数值 |
| 通信频谱效率 | 记录已定义链路的 $\log_2(1+\mathrm{SNR})$，说明聚合和用户关联 | bit/s/Hz；若报告 bit/s，应明确带宽 |
| 感知代理 | 明确的感知 SNR 或距离衰减代理，说明聚合方式 | 不命名为位置 RMSE 或完整 CRB |
| 含碰撞回合比例 | 至少一次发生机间距离小于阈值的回合数 / 总评估回合数 | 同时报告分子、分母和阈值 |
| 最小机间距 | 整个回合中各不同无人机对的最小距离 | m；离散采样不证明步间安全 |
| 越界比例 | 按回合或时间步定义边界违反事件 | 先报告裁剪前事件，说明边界处理 |
| 速度代价 | 按奖励实现独立累计 | 代理代价，不标成 J |
| 动作变化 | 相邻动作差或 jerk 相关统计，给出明确公式 | 用于平滑性，不能只看轨迹外观 |
| 推理延迟 | 部署Actor及必要预处理的 batch=1 延迟 | ms；注明硬件、预热、p50/p95和测量次数 |

真实推进能量仅在参数完整且按功率模型积分时报告：

$$
E=\sum_t P(v_t)\Delta t.
$$

训练使用不同奖励的消融变体，也应使用同一套外部通信、感知和安全指标评估。不能用“一个奖励为正、另一个为负”判断算法胜负。

## 5. 随机性与统计

训练种子与评估场景种子分开管理。所有变体使用相同的独立测试场景集合；不能在看到测试结果后反复调整超参数。检查点选择只依据预先指定的规则或独立验证场景。

推荐的聚合顺序：先对每个训练种子的若干评估回合求统计量，再在独立训练种子之间计算均值、分布与不确定性。成千上万个同一训练轨迹的时间步不能充当成千上万次独立训练。

发布结果时至少给出各次结果、平均数以及误差条的定义。若报告 95% 置信区间，写明计算方法、重采样单位、重复次数与假设。少种子时区间可能很宽；不应只选择最佳种子或把平滑线的阴影当作统计区间。

曲线同时保留原始数据。图注中写明平滑窗口、训练预算、种子数、横轴步数口径和阴影含义。

## 6. 后续实验

| 实验 | 控制变量 | 应回答的问题 |
| --- | --- | --- |
| 无关特征扰动 | 特征维数、幅度及是否重训 | 对无关输入的敏感性是否改善？ |
| 实际观测误差 | 定位误差、缺失观测或通信延迟，先选择一种 | 与训练条件不一致时性能如何退化？ |
| 通信—感知权衡 | 3至5组奖励权重分别训练 | 是否得到有意义且安全的折中？ |
| 泛化 | 新初始位置、用户布局、任务密度 | 固定模型能否在未见场景中工作？ |
| 系统扩展 | 实体数量、mask、网络输入支持 | 更多无人机时计算和性能如何变化？ |

带噪重训和固定模型的测试扰动是两种问题，必须分别标注。增加无人机数量前先确认实体接口支持，不能默认具有零样本规模泛化能力。权重扫描的经验非支配点也不证明全局 Pareto 最优。
