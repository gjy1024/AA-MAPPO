# 局限性与结论边界

公开局限性便于读者理解研究适用范围，也为后续实验提供方向。下列边界不等于否定方法；它们用于约束结论与当前证据保持一致。

## 1. 仿真与现实

论文任务使用固定高度下的二维运动和理想化信道。它不等于包含飞行姿态、气动、风场、遮挡、感知误差和通信协议栈的完整无人机系统。尚无对应记录时，应明确“仿真研究”，不能声称已通过硬件在环或真实飞行验证。

平台中的轨迹回放也不改变这一证据级别。播放流畅、地图美观或动画中未碰撞，都不能替代真实评估数据。

## 2. 4维无关特征不是射频抗干扰

向观测追加4个随机数，检验的是模型忽略无关输入的能力。真实无线干扰需要在信道、SINR、测量或协议模型中定义干扰源及其影响。不能将这项实验直接扩展表述为“复杂电磁环境下可靠抗干扰”。

## 3. 感知代理不是完整定位精度

距离四次方衰减的感知 SNR 可以作为任务代理。完整 CRB 需要测量模型、Fisher 信息和目标参数定义；实际定位 RMSE 还需要估计器及真值对照。没有这些过程时，只报告当前代理指标。

## 4. 碰撞惩罚不是硬安全保证

有限负奖励可能与其他收益发生权衡。即使采样时刻未违反安全距离，也不自动保证两个采样时刻之间的安全。应报告碰撞事件、最小间距、场景数量和分母；使用“降低碰撞风险”或“在所测场景中观察到……”这类与证据一致的表述。

若未来引入安全投影、控制屏障函数或约束强化学习，应另列为扩展方法，并单独验证其假设、可行性和计算开销。

## 5. 速度代价不是完整能耗

论文式 (21) 是速度二范数的负项，并非速度平方、加速度惩罚或真实推进能量。报告续航提升需要完整能耗参数、任务完成口径和能量积分。较低的速度代价或较平滑的轨迹不能直接推出更低的总能耗。

## 6. PPO和加权奖励的结论边界

PPO裁剪代理目标能抑制部分过大策略更新的激励，但不能把实际概率比硬限制在裁剪区间，也不保证真实性能严格单调提升。CTDE提供训练上下文，不会自动消除多智能体非平稳性。

单组加权奖励训练的经验收敛不证明 Pareto 最优或全局最优。若讨论通信—感知折中，应增加权重扫描、分项指标和支配关系分析，仍需限定为所测条件下的经验结果。

## 7. 注意力机制与解释

当前公开历史版本曾将整个观测变成单个 token 后调用 MHA。Softmax只有一个候选时权重恒为1，不能承担多实体选择功能。维护版若修正为实体token，需要重新训练并验证；历史性能不能直接转移给修正后的网络。

注意力权重可用于观察聚合行为，但热力图本身不证明因果解释。不能预先把某个头命名为“避碰头”并当作已验证结论，应结合消融、扰动和相关分析。

## 8. 公开材料与统计范围

本地已经恢复四组历史训练日志、检查点和截图，这改善了可追溯性。文件存在不自动补齐随机种子、完整配置、独立评估与论文图的对应关系，也不证明维护版经过了完整训练。

单次轨迹不能代表总体性能。未提供多训练种子、独立测试场景和统计定义时，不应生成“提升百分比”“零碰撞率”或置信区间。论文图像中深浅曲线的统计意义不明确时，也不能自行解释成均值和方差。

论文未报告的物理或训练参数，需要在维护版中作为新增实现选择明确列出。不能补一个值后声称恢复了原实验的唯一设置。

## 9. 版本与许可

历史日志（legacy）、维护修正版的短链路验证（maintenance smoke）、规则控制教学演示（illustrative）、完整扩展实验应分别记录。论文正文、软件、数据和网站资源可能适用不同的权限或许可。本维护包已提供软件LICENSE与第三方通知，但新增来源仍需逐项核查，不替第三方授予其未许可的权利。

软件DOI用于持久引用，并不代表科学正确性已经获得认证。同学独立复跑应据实记录，不自行使用出版机构的认证徽章。

## 推荐对外表述
